# Recorded aggregate result tables

These nine CSVs transcribe the corrected Paper 1 R2 manuscript result tables.
They retain the reported rounding, labels and denominators. They are reference
outputs for inspecting the reported results, NOT raw inputs, full-precision model
outputs or evidence that the national model has been rerun.

`table_inventory.json` records each table's original label and caption. Percentage
columns deliberately retain their printed percent signs and range notation.
None of these files contains individual or household records, station coordinates,
raw MOT data or source POIs. The aggregate values were extracted without changing
the scientific calculations. The source manuscript itself is not distributed.

Full national replication still needs the frozen flow/OA attributes and upstream
inputs listed in `reproducibility/paper1_r2/README.md`. Code and source-data rights
remain governed by `SOURCE_RIGHTS.md`; this transfer introduces no new licence.

File-integrity hashes are recorded in `aggregate_manifest.json`.
