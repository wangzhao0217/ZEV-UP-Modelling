# Licensing status

The transferred calculation code and test fixtures are provided by the repository owner for inspection and reproducibility work. This transfer does not select a new project-wide open-source licence or grant rights over third-party inputs. The source snapshot did not supply a project licence for these files.

The authors should select an explicit software licence and a separate appropriate licence for their own shareable derived tables/test data before describing unrestricted reuse rights. Original attribution and provider terms continue to apply to census, travel-survey, charging, road-network, POI and registration inputs. No claim is made that all of those inputs share one open-data licence.

The included example CSVs were created as fictional test data; the reference CSVs are transcriptions of rounded manuscript tables. Neither category is an extract of personal MOT or household microdata.
